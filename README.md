# NOIR Contact Form 10X
Open `contact-10x.html`.
Six-step cinematic/editorial enquiry flow with project, scale and budget selectors, animated progression, validation and success state.
The submit handler is frontend-only; connect it to your production API/email endpoint.
Reachable from the main slider (`index.html`) via **MENU → CONTACT** and the finale's **START A COMMISSION** CTA.
